# Connect Talk — app para iPhone e Android

App dos atendentes (Fila, Meus atendimentos, Conversa, Avisos e Você), em React Native com Expo.
Fala com o mesmo servidor PHP do Talk. Guia completo: [docs/app-movel.md](../docs/app-movel.md).

```bash
npm install
npm test                       # funções puras
npx expo export --platform android   # confere que o app compila
npx expo start --dev-client    # com o build de desenvolvimento instalado no celular
```
